1. 처리하는 정보와 목적

차곡 가계부는 사용자가 입력한 수입·지출 금액, 날짜, 은행명, 계좌번호, 대출 참고 원금, 메모와 완료 상태를 휴대폰 안에서 처리해 가계부 기록과 월별 집계를 제공합니다. 6자리 비밀번호는 앱 잠금을 위해 사용하며 원문으로 저장하지 않습니다.

2. 기기 내 보관

가계부 데이터는 앱 전용 저장소에 암호화해 보관합니다. 회원가입이나 서버 계정이 없으며, 개발자 서버로 데이터를 수집·전송하지 않습니다. 광고, 분석 및 추적 SDK를 사용하지 않습니다. 인터넷, 연락처, 위치, 문자 접근 권한을 요청하지 않습니다.

3. 백업·복원과 계좌 복사

사용자가 백업을 실행하면 별도로 정한 비밀번호로 암호화한 파일을 Android 파일 선택창에서 지정한 위치에 저장합니다. 클라우드 저장소를 선택하면 해당 서비스의 정책이 적용됩니다. 백업에는 가계부 기록이 포함되고 앱 잠금 비밀번호는 포함되지 않습니다. 복원 시 확인 후 기존 기록을 교체합니다. 계좌번호 복사를 누르면 해당 번호가 시스템 클립보드에 복사됩니다.

4. 보관 기간과 삭제

기록은 사용자가 삭제하거나 Android 설정에서 앱 데이터를 삭제하거나 앱을 제거할 때까지 기기에 보관됩니다. 항목 수정 화면에서 개별 기록을 삭제할 수 있습니다. 별도로 저장한 백업 파일과 클립보드 내용은 해당 저장소나 시스템에서 직접 삭제해야 합니다. 개발자는 기기에 저장된 기록에 접근하거나 삭제를 대신할 수 없습니다.

5. 보안과 복구

앱을 벗어나면 6자리 비밀번호로 다시 잠기며, 5회 입력 실패 시 30초 동안 재입력이 제한됩니다. 백업 파일은 AES-256-GCM으로 암호화합니다. 앱 비밀번호와 백업 비밀번호의 조회·복구는 제공하지 않습니다. 앱 데이터 삭제 전 백업 파일과 백업 비밀번호를 확인해 주세요.
